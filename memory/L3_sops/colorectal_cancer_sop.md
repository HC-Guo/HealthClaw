# 结直肠癌诊断SOP (Colorectal Cancer)

> 来源: GeneReviews NCBI (Lynch Syndrome, 2021)
> 创建: 2026-03-04 | 类型: 遗传性肿瘤综合征

## 临床特征

Lynch综合征（遗传性非息肉病性结直肠癌）特征：
- **核心癌症**: 结直肠癌(CRC)、子宫内膜癌、卵巢癌
- **其他相关**: 胃癌、小肠癌、尿路癌、肝胆管癌、胶质母细胞瘤、皮脂腺肿瘤、胰腺癌、前列腺癌

## 诊断标准

### 1. 临床警示特征（触发基因筛查）
| 特征 | 描述 |
|------|------|
| 家族史 | 一级亲属确诊CRC或子宫内膜癌 |
| 早发 | CRC诊断年龄<50岁 |
| 多发 | 本人或家族成员患多种Lynch相关癌症 |
| 肿瘤病理 | MSI-H/dMMR表型（微卫星高度不稳定/错配修复缺陷） |

### 2. 遗传学确诊
通过分子遗传检测发现MMR基因杂合致病性变异：
- **MLH1** (最常见)
- **MSH2**  
- **MSH6**
- **PMS2**
- **EPCAM** (epithelial cell adhesion molecule)

## 工具调用策略

### 基因检测优先级
1. **query_genetic_risk by_gene**: MLH1, MSH2, MSH6, PMS2, EPCAM
   - 成本: 0.2 per gene
   - 建议: 家族史阳性或早发CRC时优先检测

2. **query_genetic_risk by_prs**: colorectal_cancer
   - 成本: 0.2
   - 用于: 散发性CRC风险评估

### 适用场景
- CRC患者 + 家族史阳性 → 必查MMR基因
- 早发CRC (<50岁) → 优先查MSH2/MLH1
- 已知MMR变异携带者 → 家族史风险评估

## 管理建议（学习参考）
- 筛查: 20-25岁开始每1-2年结肠镜
- 预防: 阿司匹林可降低CRC风险
- 干预: 监测息肉，必要时预防性手术

## 备注
- 基因结果终身有效，可缓存
- PRS在已检出高外显率致病变异时增量价值有限
