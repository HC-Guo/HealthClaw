# 药物基因组学 (Pharmacogenomics) 临床指导 SOP

> 来源: CPIC指南 (Clinical Pharmacogenetics Implementation Consortium), 2023更新  
> 更新日期: 2026-03-04

## 一、核心基因与表型分类

### CYP2D6（最重要的药物代谢酶）
| 表型 | 活性评分 | 等位基因组合 | 人群频率(欧裔) |
|------|---------|-------------|---------------|
| **超快代谢型(UM)** | >2.0 | *1/*2×N, *2/*2×N | ~5-10% |
| **正常代谢型(EM)** | 1.0-2.0 | *1/*1, *1/*2 | ~77% |
| **中间代谢型(IM)** | 0.5 | *1/*4, *4/*10 | ~10-15% |
| **慢代谢型(PM)** | 0 | *3/*4, *4/*4, *5/*5 | ~7-10% |

### CYP2C19
| 表型 | 定义 | 人群频率 |
|------|------|---------|
| **超快代谢型(UM)** | *17/*17 | ~2-5% |
| **正常代谢型(EM)** | *1/*1, *1/*17 | ~60-70% |
| **中间代谢型(IM)** | *1/*2, *1/*3 | ~15-25% |
| **慢代谢型(PM)** | *2/*2, *2/*3 | ~2-15%(亚裔更高) |
