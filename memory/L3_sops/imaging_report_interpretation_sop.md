# 影像报告解读与随访对比 SOP

> 面向用户场景：用户提供 CT/MRI/超声/X光 等影像检查报告文本，Agent 结构化解读、标注异常、评估严重程度、对比历史、建议下一步。
> 引用: imaging_centered_decision_sop（影像决策逻辑）、evidence_grading_framework_sop（证据分级）

## 触发条件
- 用户粘贴/上传影像检查报告（CT/MRI/超声/X光/PET-CT/内镜等）
- 用户说「帮我看这个CT报告」「这个超声结果什么意思」「MRI报告解读」
- 用户上传影像图片（走视觉分析能力 + 本 SOP 协同）

## 流程

### Step 1: 报告结构化抽取
```
parse_imaging_report(report_text=报告文本, modality="CT/MRI/US/XR/PET/endoscopy")
```
抽取为标准结构：
- 检查类型 (modality): CT/MRI/超声/X光/PET-CT/内镜
- 检查部位 (body_part): 头颅/胸部/腹部/盆腔/脊柱/四肢/全身等
- 检查日期 (date)
- 对比剂使用 (contrast): 平扫/增强/双期/三期
- 发现列表 (findings): 逐条结构化
  ```json
  {
    "location": "右肺上叶",
    "description": "磨玻璃结节",
    "size": "8mm",
    "characteristics": ["边界清", "密度均匀", "无分叶"],
    "change_vs_prior": null
  }
  ```
- 结论 (conclusion): 报告原始结论
- 建议 (recommendation): 报告原始建议

### Step 2: 逐项异常解读

对每个异常发现进行解读：

**2a. 临床意义评估**

按严重程度分级：
- 🔴 **需紧急处理**: 急性脑出血、主动脉夹层、张力性气胸、肠梗阻等 → **必须建议立即就医**
- 🟠 **需尽快就诊**: 可疑恶性肿瘤、显著狭窄、活动性出血等 → 建议尽早就诊
- 🟡 **需定期随访**: 肺结节(6-8mm)、甲状腺结节(TI-RADS 3)、肝囊肿等 → 建议随访方案
- 🟢 **无需特殊处理**: 退行性改变、生理性囊肿、陈旧钙化等 → 告知正常

**2b. 通俗化翻译**

将专业术语翻译为用户能理解的语言：
```
专业术语 → 通俗解释
────────────────────────────
磨玻璃结节(GGN) → "肺里的一个小斑点，像磨砂玻璃一样半透明"
占位性病变 → "有一个不该在那里的东西占了位置"
强化不均匀 → "注射造影剂后，这个区域的血流分布不均匀"
椎间盘膨出 → "椎间盘像鼓了个包，但还没破裂出来"
低回声结节 → "超声下看到一个比周围组织颜色更深的小团块"
```

**2c. 分级标准引用（如有）**

常见分级系统的解读：
| 系统 | 适用 | 分级含义 |
|------|------|---------|
| Lung-RADS | 肺结节 CT | 1=阴性, 2=良性, 3=可能良性, 4A/4B=可疑 |
| TI-RADS | 甲状腺超声 | 1-2=良性, 3=可能良性, 4=可疑, 5=高度可疑 |
| BI-RADS | 乳腺影像 | 0=需补充, 1=阴性, 2=良性, 3=可能良性, 4-5=可疑/高度可疑 |
| LI-RADS | 肝脏 CT/MRI | LR-1=确定良性, LR-3=中间, LR-5=确定HCC |
| PI-RADS | 前列腺 MRI | 1-2=低, 3=中间, 4-5=高度可疑 |

### Step 3: 历史对比（如有既往报告）

```
compare_imaging_reports(current=当前报告, prior=既往报告)
```

对比维度：
- **大小变化**: 增大/缩小/稳定（附数值和百分比）
- **形态变化**: 边界/密度/信号/血流变化
- **新发病灶**: 本次新出现的发现
- **消失病灶**: 既往存在但本次消失的发现
- **整体趋势**: 好转 / 稳定 / 进展

输出格式：
```
📊 影像随访对比 (2024-01-15 vs 2023-07-10)

右肺上叶结节:
  大小: 6mm → 8mm (+33%, ⚠️ 增大)
  形态: 由纯磨玻璃 → 混合磨玻璃（出现实性成分）
  建议: 🟠 结节增大且出现实性成分，建议胸外科就诊评估

左肾囊肿:
  大小: 15mm → 16mm (稳定)
  建议: 🟢 稳定，继续年度随访
```

### Step 4: 综合建议

根据所有发现的严重程度，给出综合建议：

```
📋 影像报告解读总结

检查: 胸部CT增强 (2024-01-15)
发现: 3 项异常 | 🟠 1项 | 🟡 1项 | 🟢 1项

🟠 [需尽快就诊] 右肺上叶磨玻璃结节 8mm，较前增大
   通俗解释: 肺里有个小斑点在变大，需要专科医生评估
   建议科室: 胸外科 / 呼吸科
   建议检查: 薄层CT复查 或 PET-CT

🟡 [定期随访] 甲状腺左叶结节 12mm (TI-RADS 3)
   通俗解释: 甲状腺里有个小团块，目前看大概率是良性的
   建议: 6个月后超声复查

🟢 [无需处理] 肝右叶囊肿 8mm
   通俗解释: 肝脏里有个小水泡，完全正常，不需要治疗

⚠️ 以上解读仅供参考，具体诊疗请咨询相关科室医生
```

### Step 5: 联动与记录

- 如发现与用户已知慢病相关 → 结合 user_profile 分析
- 如发现用药相关影像改变（如药物性肝损伤） → 可联动 medication_review_sop
- 将关键发现保存到 user_data（如结节大小用于后续对比）
- 🔴 级别发现 → 必须强烈建议就医，不能仅说"仅供参考"

## 图片直传场景

当用户直接上传影像图片（非文字报告）：
1. 利用 LLM 多模态视觉能力直接分析图像
2. 描述所见异常，给出初步判读
3. 标注哪些判读不确定，需要放射科确认
4. 建议用户同时提供文字报告以获得更准确的解读
5. 参考 imaging_centered_decision_sop 判断是否需要升级到分子检测

## 注意事项
- 影像解读仅为辅助，不替代放射科医师的正式报告
- 🔴 级别（急性/危重）发现必须最先、最醒目地提示
- 专业术语翻译要准确，不能为了通俗而失去精确性
- 对比随访时注意检查设备和参数差异可能影响测量值
- 搜索时使用通用医学术语，禁止包含用户个人信息
