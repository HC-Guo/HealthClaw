# 临床路径合规审查 SOP

> 引用基础层: evidence_grading_framework_sop（证据分级与审计框架）
> 本 SOP 覆盖：临床路径偏差提醒、医保/商保预审解释

## 触发条件
- 用户说「检查临床路径」「路径偏差」「医保预审」「费用审查」
- 用户提供诊疗方案/医嘱/费用清单要求合规检查
- 用药审查(medication_review)发现适应症不匹配时自动联动

## 流程

### Step 1: 诊疗信息收集
```
extract_medical_record(raw_text=...) → 结构化病历
load_user_profile()                 → 医保类型、诊断信息
```
重点提取:
- 主要诊断 + 合并症
- 住院天数 / 就诊类型
- 检查检验项目清单
- 用药方案（药名、剂量、疗程）
- 手术/操作
- 费用明细（如有）

### Step 2: 临床路径匹配
```
check_pathway_compliance(
  diagnoses=[...],
  treatment_plan={...},
  check_type="pathway"  # pathway / insurance / both
)
```
匹配策略:
1. 内置规则: 常见病种路径要点（如社区获得性肺炎、急性心梗、髋关节置换等）
2. 不确定时: `web_search("XX病 临床路径 2024 卫健委")` 搜索官方路径
3. 低置信度匹配: 标注 ⚠️，建议人工确认路径版本

### Step 3: 逐项合规比对

**3a. 临床路径偏差检查**

| 检查维度 | 检查内容 | 偏差示例 |
|---------|---------|---------|
| 住院天数 | 是否超出路径规定 | 路径≤10天，实际15天 |
| 必做检查 | 路径要求的检查是否完成 | 路径要求心电图，未做 |
| 禁做项目 | 是否有路径外非必要项目 | 路径外高价检查 |
| 用药规范 | 是否符合路径推荐用药 | 使用路径外抗生素 |
| 手术时机 | 手术是否在规定时间窗内 | 急诊手术延迟 |
| 出院标准 | 是否达到出院条件 | 指标未达标提前出院 |

每个偏差输出:
```
⚠️ 偏差: [偏差描述]
   路径要求: [条款原文]
   实际情况: [具体数据]
   📎 证据: [T3] 《XX病临床路径(20XX版)》§X.X
   风险等级: 🔴高/🟡中/🟢低
   建议措施: [如"补充XX检查"/"调整用药方案"/"补充变异说明"]
```

**3b. 医保/商保预审**

| 检查维度 | 检查内容 |
|---------|---------|
| 适应症匹配 | 诊断是否符合药品/检查的医保适应症限定 |
| 限定条件 | 是否满足限二线/限三级等前置条件 |
| 自费项目 | 标注不在目录内的项目 |
| 大额预警 | 单项费用超阈值时预警 |
| 重复收费 | 同类检查/用药重复 |

每个问题输出:
```
⚠️ 医保风险: [问题描述]
   目录规定: [限定条件原文]
   当前情况: [具体情况]
   📎 证据: [T3] 《国家医保药品目录(20XX版)》/ 地方目录
   预计影响: [可能拒付金额/需补材料]
   建议: [如"补充用药理由"/"改用目录内替代药"]
```

### Step 4: 生成合规报告
```
ask_user → 展示完整报告，逐项确认
```
报告格式:
```
═══════════════════════════════════════════
  临床路径合规审查报告
═══════════════════════════════════════════
  诊断: 2型糖尿病伴周围神经病变 (E11.4)
  路径版本: 《2型糖尿病临床路径(2024版)》
  审查模式: pathway + insurance
───────────────────────────────────────────
  路径偏差: 🔴 1项 | 🟡 2项 | 🟢 1项
  医保风险: ⚠️ 2项
───────────────────────────────────────────
  [详细问题列表...]
───────────────────────────────────────────
  引用来源汇总:
    [T3] 《2型糖尿病临床路径(2024版)》§3.2, §4.1
    [T3] 《国家医保药品目录(2024)》西药部分
    [T1] 2024 ADA糖尿病诊疗标准 §9
═══════════════════════════════════════════
  ⚠️ 本报告仅为辅助审查，最终以医保部门审定为准
```

### Step 5: 审计记录
每个偏差/风险项通过 `record_citation()` 记录到审计链，支持回放复现。

## 知识获取策略
- **常见病种路径**（Top 50）: 优先依赖 LLM 内置知识 + L3 SOP（如有）
- **最新路径版本**: `web_search` 搜索卫健委/国家医保局最新发文
- **地方性差异**: 标注「国家版路径，各省市可能有调整」
- **路径经验积累**: 用户修正的偏差判断写入 L4 episodes

## 注意事项
- 临床路径有合理变异，非所有偏差都是错误——区分「变异（有理由）」和「偏差（无理由）」
- 医保目录年度更新，注意版本时效性
- 搜索时使用通用术语，禁止包含患者个人信息
- 本 SOP 使用 **strict** 证据引用档位（evidence_grading_framework_sop §二）
