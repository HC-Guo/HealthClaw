# 2型糖尿病 (Type 2 Diabetes Mellitus) 诊断 SOP

## 诊断标准 (WHO/ADA)
满足以下任一条：
- **HbA1c ≥ 6.5%** (48 mmol/mol)
- **空腹血糖 ≥ 7.0 mmol/L** (126 mg/dL)
- **OGTT 2h血糖 ≥ 11.1 mmol/L** (200 mg/dL)
- **随机血糖 ≥ 11.1 mmol/L** + 典型症状

注：需重复确认（除非症状明显+随机血糖↑）

## 鉴别诊断（何时考虑基因检测）
1. 发病年龄 < 35岁 → 排除MODY/单基因糖尿病
2. 非肥胖体型但高血糖 → 排除LADA
3. 胰岛素抵抗体征显著 → 排除A型胰岛素抵抗综合征

## 遗传风险评估
- **核心基因**: TCF7L2 (最强关联位点)
- **PRS**: 有效（多基因病PRS比单基因查询更有价值）
- **适用场景**: 一级亲属发病、预测风险分层

## 蛋白标志物
- **HbA1c**: 诊断+监测金标准
- **空腹胰岛素/C肽**: 评估β细胞功能
- **炎症标志物**: IL-6, CRP（UKB蛋白组）

## 临床数据优先级
1. HbA1c（必选）
2. 空腹血糖/胰岛素
3. BMI、腰围（肥胖指标）
4. 家族史

## 基因检测决策
```
肥胖 + 中老年 + 家族史- → PRS可能有增量价值
早发 (<35岁) + 非肥胖 → 单基因panel（MODY）
家族史+ + 早发 → TCF7L2 + PRS
```

## 备注
- 基因结果终身不变，可缓存复用
- 非欧洲裔PRS效力下降，需标注不确定性
