# 房颤 (Atrial Fibrillation, AF) 诊断与风险评估 SOP

## 1. 疾病概述
- **流行病学**: 最常见的持续性心律失常，患病率随年龄增长显著上升
- **遗传贡献**: 估计遗传度~40%，常见变异为主，罕见单基因突变较少见
- **核心风险基因座**: 4q25(PITX2附近)、1q21(KCNN3)、16q22(ZFHX3)

## 2. 临床评估基础
- **症状**: 心悸、气短、胸痛、头晕、疲劳、无症状(隐匿性)
- **临床分型**: 首诊/阵发/持续/长程持续/永久性
- **CHA2DS2-VASc评分**: 卒中风险分层

## 3. 遗传风险评估流程

### 3.1 基因查询策略
| 场景 | 推荐查询 | 说明 |
|------|---------|------|
| 所有疑似/确诊AF | PITX2通路PRS | 核心风险位点 |
| 早发AF(<60岁) | PRS + 通路基因 | 遗传负荷更重 |
| 家族史阳性 | 重点关注rs2200733 | 家族史提示遗传风险 |

### 3.2 关键基因位点解读
- **rs2200733 (4q25, PITX2附近)**
  - T等位基因：风险等位基因
  - 汉族人群：T等位基因OR=1.806 (95% CI: 1.179-2.766)
  - 基因型风险分层：
    - CC：正常风险（基线）
    - TC：1.5倍风险，OR≈3.1
    - TT：高风险，OR≈5.1
  
- **rs10033464 (4q25, PITX2附近)**
  - T等位基因：1.4倍风险
  - 与rs2200733高度连锁

- **rs13376333 (KCNN3)**: 持续AF风险
- **rs7193343 (ZFHX3)**: 多族裔验证的AF风险位点

### 3.3 蛋白生物标志物
- **NT-proBNP**: 心房压力负荷标志物，AF患者升高
- 蛋白数据缺失时，正常

## 4. 诊断决策规则

### 4.1 何时需要基因检测？
- ✅ **家族史阳性**（一级亲属AF史）→ 强烈建议
- ✅ **早发AF**（<60岁确诊）→ 强烈建议  
- ✅ **原因不明卒中**（隐匿性AF筛查）→ 建议
- ✅ **消融术后复发预测** → 建议（4q25风险等位基因预测复发）
- ❌ **孤立性老年AF**（>75岁，无家族史）→ 价值有限

### 4.2 诊断置信度评估
| 证据组合 | 置信度 | 说明 |
|---------|-------|------|
| ECG+症状+PRS高分 | >0.85 | 确诊+遗传风险分层 |
| ECG正常+PRS高分 | 0.5-0.6 | 隐匿AF风险，需Holter |
| 症状+ECG正常+PRS正常 | 0.3-0.4 | 症状非AF所致可能性大 |

## 5. 工具调用优先级
1. **load_patient** (cost=0.01) - 必做
2. **query_genetic_risk by_prs** (cost=0.2) - AF核心工具
3. **query_proteomics** [NT-proBNP] (cost=0.05) - 可选，辅助评估
4. **recall_similar_cases** (cost=0.01) - 决策前调用

## 6. 临床行动建议
- **PRS高风险+无症状**：建议定期心电监测(年Holter)
- **PRS高风险+确诊AF**：强化抗凝决策，消融术前评估
- **PRS正常+确诊AF**：标准治疗，非遗传高危
