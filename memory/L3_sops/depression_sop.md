# MDD (Major Depressive Disorder) 诊断辅助SOP
> 来源: StatPearls MDD + CPIC Antidepressant Guidelines | 创建: 自主学习

## 1. 疾病概要
- 终生患病率: ~20%; 女:男≈2:1
- 遗传度(h²): ~37%, 高度多基因, 无高外显率致病基因
- 核心病理: 5-HT/NE/DA失衡 + HPA轴亢进 + GABA/谷氨酸失衡 + 神经炎症

## 2. 诊断标准 (DSM-5)
≥5/9症状，持续≥2周，必须包含①或②：
1. 抑郁心境（几乎每天大部分时间）
2. 快感缺失/兴趣丧失
3. 体重/食欲显著变化（±5%/月）
4. 失眠或嗜睡
5. 精神运动性激越或迟滞（他人可观察）
6. 疲劳/精力丧失
7. 无价值感/过度自罪
8. 注意力/决策能力下降
9. 反复死亡想法/自杀意念

**排除**: 症状非物质/躯体疾病所致；排除双相障碍；无精神分裂谱系叠加

## 3. 遗传风险评估策略
### 3a. PRS (多基因风险评分)
- GWAS: Howard2019识别102+风险位点
- PRS解释力: ~1-2%表型变异 → **研究用为主，临床增量有限**
- 适用: 群体分层研究; 个体预测不建议单独使用

### 3b. 药物基因组学 (★最具临床价值)
| 基因 | 作用 | 临床指导 |
|------|------|----------|
| CYP2D6 | SSRI/TCA代谢 | PM→减量/换药; UM→增量/换药 |
| CYP2C19 | 西酞普兰/艾司西酞普兰/舍曲林代谢 | PM→减量50%; UM→换药或增量 |
| CYP2B6 | 安非他酮代谢 | PM→减量监测毒性 |
| SLC6A4 (5-HTTLPR) | 5-HT转运体 | S/S型→SSRI反应可能较差(证据中等) |
| HTR2A | 5-HT2A受体 | 辅助预测SSRI反应(证据有限) |

**CPIC指南建议**: 治疗抵抗或严重不良反应时，优先检测CYP2D6+CYP2C19

### 3c. 风险基因 (遗传咨询参考)
| 基因 | 变异 | 效应 |
|------|------|------|
| SLC6A4 | 5-HTTLPR S等位基因 | 应激敏感性↑ |
| BDNF | Val66Met (rs6265) | 海马可塑性↓, BDNF分泌↓ |
| FKBP5 | rs1360780 T等位基因 | HPA轴脱抑制, 童年创伤交互 |
| MTHFR | C677T (rs1801133) | 叶酸代谢↓→SAMe↓→甲基化障碍 |
| COMT | Val158Met | DA/NE代谢变化, 认知表型 |

## 4. 蛋白标志物
| 蛋白 | 方向 | 临床意义 |
|------|------|----------|
| BDNF | ↓ | MDD标志; 治疗反应可追踪(↑=改善) |
| CRP | ↑ | 炎症亚型标志; ≥3mg/L提示抗炎增效 |
| IL-6 | ↑ | 炎症亚型; 与治疗抵抗相关 |
| TNF-α | ↑ | 神经炎症 |

**注意**: 无FDA批准的MDD诊断性蛋白标志物; 仅辅助亚型分类

## 5. UKB分析决策树
```
MDD患者 → load_patient
├─ 治疗抵抗/药物选择 → query_genetic_risk(by_gene, [CYP2D6, CYP2C19, CYP2B6])
├─ 家族史阳性/早发 → query_genetic_risk(by_prs, [depression]) + by_gene([SLC6A4, BDNF, FKBP5])
├─ 怀疑炎症亚型 → query_proteomics([CRP, IL-6, TNF-α, BDNF])
├─ 共病焦虑 → 同时查 COMT, MTHFR
└─ 常规评估 → PRS + BDNF蛋白即可
```

## 6. 成本注意
- PRS(0.2) + 蛋白组(0.05×4=0.2) = 0.4 基本开销
- 药物基因组(0.2) 仅在治疗决策需求时追加
- recall_similar_cases(0.01) 始终先查
