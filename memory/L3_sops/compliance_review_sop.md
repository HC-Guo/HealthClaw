# 合规材料审阅与自动引用 SOP

> 引用基础层: evidence_grading_framework_sop（证据分级与审计框架）
> 覆盖场景：医学事务材料审阅、学术推广合规、培训文档引用核查

## 触发条件
- 用户说「审阅材料」「合规审查」「引用核查」「帮我查引用」
- 用户提供学术报告/推广材料/培训文档要求检查医学声明的准确性和引用完整性

## 流程

### Step 1: 材料接收与分段
```
review_compliance_material(
  text=材料文本,
  material_type="academic/promotion/training/regulation",
  review_scope="full/claims_only/references_only"
)
```
将材料拆解为:
- **医学声明 (Claims)**: 涉及疗效、安全性、流行病学数据的陈述
- **引用标注 (References)**: 材料中已标注的参考文献
- **推荐性语句**: 含「应该/建议/推荐/首选」等措辞的语句
- **数据引用**: 含具体数字（发生率/有效率/p值等）的语句

### Step 2: 逐条声明验证

对每条医学声明执行:

**2a. 声明-引用匹配**
- 检查该声明是否有对应引用
- 引用是否真实存在（PMID/DOI 可验证时用 web_search 确认）
- 引用内容是否真正支持该声明（防止断章取义）

**2b. 证据分级**
按 evidence_grading_framework_sop 的 T1-T6 体系给每条声明的证据评级:
```
声明: "XX药可降低心血管事件风险30%"
→ 引用: Smith et al. NEJM 2023 (PMID: 12345678) [T1-RCT]
→ 核实: web_search("PMID 12345678") → 确认结论一致 ✅
→ 评级: T1 | 置信度: 高
```

**2c. 合规性检查**

| 检查项 | 不合规示例 |
|--------|-----------|
| 超适应症推广 | 推广材料声称适应症 A，但说明书仅批准适应症 B |
| 夸大疗效 | 引用亚组分析结果作为全人群结论 |
| 隐藏风险 | 只引用有效性数据，未提及安全性警告 |
| 过时引用 | 引用被撤稿/更新的文献 |
| 未标注来源 | 医学声明无任何引用支撑 |
| 绝对化措辞 | 使用「治愈/根治/100%有效」等违规表述 |

### Step 3: 证据缺失与告警

对每条问题标注:
```
[声明位置] 第X段第Y句
[原文] "XX药是治疗YY的首选方案"
[问题类型] 证据不足 / 引用缺失 / 超说明书 / 措辞不当
[严重程度] 🔴必须修改 / 🟡建议修改 / 🟢可选优化
[现有证据] T{n} — {来源} / ⚠️ 无证据
[建议修改] "根据XX指南(20XX)，XX药是治疗YY的推荐方案之一"
[补充引用] {建议添加的引用}
```

### Step 4: 自动生成参考文献列表

根据审阅过程中查找到的证据，自动生成/补全参考文献:
```
参考文献:
[1] 2024 ESC慢性冠脉综合征指南. European Heart Journal. [T1]
    — 支撑声明: 第2段, 第5段
[2] 氯吡格雷药品说明书(国药准字HXXXXXXXX). [T3]
    — 支撑声明: 第3段
[3] Wang et al. Lancet 2023; 401:1234-45. PMID:12345678. [T4]
    — 支撑声明: 第7段
    ⚠️ 单篇研究，建议补充指南级证据
```

### Step 5: 输出审阅报告
```
ask_user → 展示完整审阅结果
```

报告格式:
```
═══════════════════════════════════════════
  合规材料审阅报告
═══════════════════════════════════════════
  材料类型: 学术推广幻灯片
  声明总数: 12条 | 引用总数: 8条
───────────────────────────────────────────
  审阅结果:
    ✅ 合规声明: 8 条
    🔴 必须修改: 1 条（超适应症推广）
    🟡 建议修改: 2 条（引用不足）
    🟢 可选优化: 1 条（可补充更高级证据）
───────────────────────────────────────────
  证据覆盖:
    T1(指南/RCT): 4条 | T2(共识): 2条
    T3(说明书): 1条 | T4(文献): 1条
    ⚠️ 无证据: 2条 | T6(AI推理): 2条
───────────────────────────────────────────
  [详细问题列表...]
───────────────────────────────────────────
  自动生成参考文献列表（共 10 条）
═══════════════════════════════════════════
  ⚠️ 本审阅仅为辅助，最终以医学事务/法务部门审定为准
```

### Step 6: 审计记录
全部声明验证过程通过 `record_citation()` 写入审计链。
支持回放：哪条声明、用什么证据验证、查阅了哪些工具、结论是什么。

## 与其他 SOP 联动
- 材料中涉及用药安全声明 → 可调用 medication_review_sop 交叉验证
- 材料中涉及诊断流程 → 可调用对应疾病 SOP 验证准确性
- 材料中涉及 ICD 编码 → 可调用 icd_coding_sop 验证编码准确性

## 注意事项
- 本 SOP 使用 **strict** 证据引用档位
- web_search 用于验证 PMID/DOI 真实性和文献结论，搜索时仅使用学术信息
- 药品推广合规性因国家/地区不同而异，默认参考中国药品管理法规
- 审阅意见为辅助参考，涉及法律合规问题应咨询专业法务
