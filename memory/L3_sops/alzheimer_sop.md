# 阿尔茨海默病 (Alzheimer's Disease) 诊断 SOP

## 诊断标准 (NIA-AA/ATN框架)
- **临床核心**: 认知功能进行性下降，影响日常生活
- **生物标志物支持**:
  - Aβ: CSF Aβ42↓或淀粉样PET+
  - Tau: CSF p-tau↑或tau PET+
  - 神经退行性: MRI海马/颞叶萎缩，或FDG-PET顶颞叶代谢↓

## 临床评估
- **MMSE/MoCA**: 认知筛查
- **CDR**: 临床痴呆评定
- **脑MRI**: 海马体积、皮质厚度、排除其他病变

## 遗传风险评估
- **必查基因**: APOE (ε2/ε3/ε4等位基因)
  - ε4: 风险等位基因，剂量效应（杂合↑3倍，纯合↑12倍）
  - ε2: 保护性
- **PRS**: 中等效力，可作为APOE补充
- **早发(<65岁)**: 加查APP, PSEN1, PSEN2（家族性AD）

## 蛋白标志物（UKB可用）
- **NFL**: 神经轴突损伤标志物，疾病活动度
- **GFAP**: 星形胶质细胞激活标志物
- **其他研究标志物**: YKL-40, NPTXR

## 基因检测决策流程
```
所有疑似AD → APOE基因型
    ↓
早发 (<65岁) → 加查APP/PSEN1/PSEN2
家族史阳性 → 家系连锁分析
    ↓
APOE ε4+ → 高风险分层，密切监测
```

## 注意事项
- APOE检测主要用于风险评估，非诊断标准
- AD确诊需生物标志物支持（临床实践中）
- 鉴别诊断：血管性痴呆、Lewy体痴呆、额颞叶痴呆

## UKB数据利用建议
1. 临床诊断困难时，APOE提供遗传风险信息
2. NFL/GFAP可反映神经退行程度
3. 脑MRI特征（海马体积）为关键影像指标
