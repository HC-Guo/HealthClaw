## 1. 核心原则: 证据缺口分析 > 成本阈值

### 1.1 旧模式 vs 新模式

| 维度 | 旧模式 (成本中心) | 新模式 (证据中心) |
|------|------------------|------------------|
| 决策触发 | cost < 0.05 → 查 | 证据缺口类型 → 选工具 |
| 工具选择 | 低成本优先 | 最能填补缺口者优先 |
| 停止条件 | 成本耗尽 | 置信度达标 |

### 1.2 证据缺口分析框架

```
Step 1: 当前置信度评估 (0-1)
├── 影像证据质量? (结构/功能/分子)
├── 临床数据充分性? (症状/体征/实验室)
└── 已有分子证据? (基因/蛋白/代谢)

Step 2: 缺口类型判定
├── 形态学缺口 → 影像优先
├── 遗传背景缺口 → 基因优先  
├── 功能状态缺口 → 蛋白优先
└── 多轴冲突 → 启动冲突解决

Step 3: 工具选择 (三轴决策)
```

## 2. 三轴证据决策树

### 2.1 影像轴 (Imaging-First)

**影像充分性判定标准:**
- **充分** (影像可直接诊断): 
  - 病灶边界清晰 + 特征典型 + 与临床一致
  - → 跳过基因/蛋白，直接诊断
  
- **不充分** (需分子验证):
  - 影像模糊/非典型/多发病变
  - → 影像 + 基因/蛋白联合

- **冲突** (影像-临床不符):
  - 影像阴性但症状典型，或影像阳性但无症状
  - → 优先基因排查遗传病表型变异

### 2.2 基因轴 (Genetics-First)

**强制查基因条件:**
- 家族史阳性 + 任何影像/临床异常
- 早发疾病 (<50岁，依疾病调整)
- 已知基因型-表型强关联 (如HCM-MYH7)
- 多系统受累提示综合征

**基因可跳过条件:**
- 老年散发性疾病 + 影像典型
- 获得性病因明确 (感染/创伤/药物)

### 2.3 蛋白轴 (Proteomics-First)

**蛋白优先场景:**
- 影像阴性但怀疑功能异常
- 需要动态监测 (治疗反应/复发)
- 基因结果已明确，需功能验证

**蛋白可跳过场景:**
- 基因已找到高外显致病变异
- 影像已明确诊断且无需分期

## 3. 决策流程图

```
开始诊断

    │
    ▼

    │ 不充分/冲突
    ▼
┌─────────────────┐     有        ┌──────────┐
│ 3. 家族史/早发?  │ ───────────► │ 查基因   │
└─────────────────┘              └──────────┘
    │ 无

```

## 4. 冲突解决规则 (三轴数据不一致时)

**优先级规则 (由高到低):**
1. **形态学证据** (影像可见的结构性改变)
2. **遗传证据** (明确致病/可能致病变异)
3. **功能证据** (蛋白/代谢标志物)
4. **临床印象** (症状/体征，最低优先级)

**处理流程:**
```
影像A vs 基因B vs 蛋白C 冲突
    │
    ├── 影像 vs 基因冲突 → 查表型-基因型关联数据库
    │                      (如HCM的MYH7突变对应特定影像特征)
    │
    ├── 影像 vs 蛋白冲突 → 考虑疾病阶段 (早期蛋白↑, 晚期影像↑)
    │
    └── 三轴均冲突 → 重新评估: 是否多种疾病共存? 样本错误?
```

## 5. 置信度评估标准

| 置信度 | 标准 | 所需证据 |
|--------|------|---------|
| 0.9-1.0 | 确诊 | 影像典型 + 基因确认/临床金标准 |
| 0.7-0.9 | 很可能 | 影像+临床一致，或基因+蛋白一致 |
| 0.5-0.7 | 可能 | 单一强证据，或多项弱证据一致 |
| 0.3-0.5 | 不确定 | 证据矛盾或证据不足 |
| <0.3 | 排除/其他诊断 | 关键证据阴性 |

## 6. 执行检查清单

- [ ] 哪种工具最能填补缺口?
- [ ] 是否需要多轴联合?
- [ ] 预期置信度提升多少?
- [ ] 是否有来自L4的类似经验?
