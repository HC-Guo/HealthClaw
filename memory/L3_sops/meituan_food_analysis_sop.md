# 美团外卖订单健康分析 SOP

> **must call update working ckp**：`美团外卖分析｜仅任务开始首次check_connection｜每步操作后视觉确认（仅失败/疑似断开时重查）｜3-10单足够｜支付操作必须ask_user`

## 核心流程（4步）

### 1. 连接手机
```
phone_control(action="check_connection")
```
- ✅ 成功：显示手机型号，继续
- ❌ 失败：提示用户检查USB连接和调试授权
- 后续步骤不要重复显式 check_connection；仅当工具执行失败/疑似未连接时再重查

### 2. 打开美团外卖App

**推荐方法：直接启动（优先尝试）**
```python
phone_control(action="launch_app", app="美团")
# 或 app="com.sankuai.meituan"  # 美团主App完整包名
```

**包名说明：**
- ✅ **推荐**：`app="美团"`（简单包名，系统自动匹配）
- ✅ 备选：`app="com.sankuai.meituan"`（美团主App完整包名）
- ❌ **不推荐**：`app="com.sankuai.meituan.takeoutnew"`
  - 原因：该包名的默认Activity可能不存在或需要额外参数
  - 实践经验：多次测试失败，报错"MainActivity not found"

等待2秒让App加载。

### 3. 进入订单列表

**Step 1: 识别当前页面**
```
phone_screen_analyze(question="当前是什么页面？如何进入订单列表？")
```

**Step 2: 动态定位并点击**
- 美团外卖App：底部"订单"按钮
- 美团主App：进入"我的" → "全部订单"

**关键原则：不要硬编码坐标！**
1. 优先使用原子动作：`phone_control(action="tap_keyword_confirm", keyword="订单")` 或 `keyword="全部订单"`（内部已封装 `ui_dump -> 点击 -> 确认`）
2. 若原子动作返回未命中/不确定，再用 `ui_dump(keyword="订单", clickable_only=true)` 手动定位并点击
3. 只有在 `ui_dump` 无法定位时，才使用 `phone_screen_analyze` 视觉兜底
4. 点击后用 `phone_screen_analyze` 做一次最终页面确认（是否已进入订单列表）

### 4. 收集订单信息

**推荐：视觉分析 + 滚动（3-10单足够）**

```
phone_screen_analyze(question="列出当前屏幕所有订单：时间、店名、菜品、金额")
```

**操作流程：**
1. 截图分析当前屏幕订单（通常3-5单）
2. 向下滚动：`phone_control(action="scroll_down")`
3. 等待0.5秒，再次截图分析
4. 重复2-3步，直到满足以下任一停止条件：已收集3-10单、已覆盖到目标分析时间边界、或到达底部

**时间边界停止：**
- 若任务目标是“最近一周/最近X天”，当订单日期已覆盖到早于该时间边界时即可停止滚动，无需继续翻到底

**判断到底：** 连续2次滚动看到相同订单

**为什么3-10单足够？**
- 3单：最低有效样本，能看出基本趋势
- 10单：平衡成本和数据量，覆盖1-2周
- 超过10单：边际收益递减，浪费时间

## 健康分析维度

### 数据结构化
```json
{
  "orders": [
    {
      "date": "2024-03-10 12:30",
      "restaurant": "XX快餐",
      "items": ["宫保鸡丁", "米饭"],
      "total_price": 28.5,
      "category": "中式快餐"
    }
  ]
}
```

**菜品分类：**
- 中式快餐：盖饭、炒菜、面食
- 西式快餐：汉堡、披萨、炸鸡
- 奶茶饮品：奶茶、果茶、咖啡
- 健康轻食：沙拉、轻食套餐
- 夜宵烧烤：烧烤、小龙虾、炸串
- 甜品零食：蛋糕、冰淇淋

### 分析维度
1. **频次分析**：每周外卖次数、高峰时段
2. **菜品类型**：各类别占比、高油高盐频率、蔬菜摄入
3. **营养结构**：碳水/蛋白质/脂肪/膳食纤维推断
4. **健康风险**：高糖（奶茶）、高油脂（炸鸡烧烤）、缺蔬菜、夜宵习惯

### 健康评分（1-10分）
- 8-10分：外卖少、蔬菜多、营养均衡
- 5-7分：频次适中、有改善空间
- 3-4分：高频外卖、高油高盐、缺蔬菜
- 1-2分：严重不健康（每天外卖+奶茶+烧烤）

## 关键原则

### ✅ 必须做
- 每步操作后用 `phone_screen_analyze` 确认结果
- 动态定位坐标（ui_dump或视觉分析），不硬编码
- 3-10单足够分析，无需过度滚动
- 涉及支付操作必须 `ask_user` 确认

### ❌ 不要做
- 不要点击"再来一单"或"去支付"
- 不要将订单详情写入长期记忆（隐私保护）
- 不要依赖硬编码坐标（UI会变化）
- 不要重复截图同一屏幕

### 🔧 错误处理
- **启动失败**：改用包名重试（`app="com.sankuai.meituan"`），并用 `current_app` 检查前台应用
- **找不到按钮**：用 `phone_screen_analyze` 动态定位
- **App闪退**：重新启动，多次失败询问用户
- **误触支付**：立即 `press_key(back)` 返回

## 性能优化

- **快速查看（3-5单）**：1-2次截图
- **标准分析（10单）**：3-4次截图+滚动
- 每次滚动后等待0.5秒让页面稳定
- 避免重复分析同一订单

## 备选方案：UI Dump

如果 `phone_screen_analyze` 不可用，使用：
```
phone_control(action="ui_dump")
```

**局限性：**
- 可能无法获取完整菜品信息
- 需要点击订单进入详情页

**提取信息：**
- 店名：较大字号文本
- 金额：包含"¥"符号
- 时间：日期格式（如"03-10"）
