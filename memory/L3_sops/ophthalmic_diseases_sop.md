# 眼科疾病风险评估与诊断 SOP

> 数据来源: PubMed/DuckDuckGo搜索验证 (2026-03-03)
> 证据等级: B级（多源文献综述一致性）

## 一、主要眼科疾病分类与诊断要点

### 1. 青光眼 (Glaucoma)
- **分型**: 原发性开角型(POAG,最常见)、闭角型、正常眼压型(NTG)、先天性
- **关键指标**: 眼压(IOP)↑、视神经杯盘比(C/D ratio)↑、视野缺损、RNFL变薄
- **遗传基因**: MYOC(3-4% POAG,IOP>21mmHg), OPTN(~1% NTG), TBK1(~1% NTG) — 均为常染色体显性
- **风险因素**: 年龄>60、家族史、高眼压、非裔、高度近视、糖尿病
- **PRS**: 有效(数百个位点)，成人发病型为多基因遗传
- **影像**: retinal(视网膜OCT)查RNFL厚度是关键

### 2. 年龄相关性黄斑变性 (AMD)
- **分型**: 干性(萎缩型,90%)、湿性(新生血管型,10%但视力威胁更大)
- **关键指标**: 玻璃膜疣(drusen)、RPE改变、黄斑区萎缩/出血
- **遗传基因**: CFH(补体因子H,最强关联), ARMS2/HTRA1(10q26), C3, C2/CFB
- **通路**: 补体通路是核心发病机制
- **蛋白标志物**: 血浆补体组分(C3a, C5a, CFH)、VEGF(湿性AMD)
- **风险因素**: 年龄>55、吸烟(最强可干预因素)、家族史、欧洲裔
- **影像**: retinal(OCT查玻璃膜疣和RPE)

### 3. 糖尿病视网膜病变 (DR)
- **分期**: 非增殖型(NPDR: 轻/中/重)→增殖型(PDR)；可伴黄斑水肿(DME)
- **关键指标**: HbA1c、血糖控制、病程、血压、微量白蛋白尿
- **遗传**: 多基因，无单一高外显率基因；VEGF通路相关变异有报道但临床意义有限
- **蛋白标志物**: VEGF(核心致病因子)、IL-6、TNF-α、CRP（炎症标志物）；目前无特异早期生物标志物
- **风险因素**: 糖尿病病程>10年、HbA1c>7%、高血压、血脂异常、肾病
- **影像**: retinal(眼底照+OCT)是筛查金标准
- **注意**: DR诊断主要依赖临床指标(HbA1c/血糖)+眼底影像，基因检测增量价值小

### 4. 视网膜色素变性 (RP) / 遗传性视网膜病变 (IRD)
- **特征**: 进行性感光细胞退化，夜盲→周边视野丧失→管状视野→失明
- **遗传**: 极高异质性(>80个致病基因)；AD/AR/X-linked均有
- **核心基因**: RHO(AD-RP最常见), RPGR(X连锁RP), USH2A(AR-RP/Usher综合征), RP1, RPE65
- **伴随**: 后囊下白内障(39-72%)、高度近视、散光、圆锥角膜
- **注意**: 家族史对遗传模式判断至关重要；基因检测对RP几乎总是值得的
- **影像**: retinal(OCT查光感受器层)

### 5. 其他重要眼科疾病
- **白内障**: 年龄相关最常见，遗传性(先天性)涉及CRYAA/CRYBB2等晶状体蛋白基因；多数无需基因检测
- **高度近视**: 与IRD高度关联，X连锁视网膜病尤为常见；>-6D需警惕视网膜脱离
- **圆锥角膜(Keratoconus)**: VSX1、SOD1关联；角膜地形图诊断
- **高血压视网膜病变**: 诊断依赖眼底分级(Keith-Wagener分级)，与全身血压管理相关

## 二、标准诊断流程

1. **load_patient** → 检查: 年龄、糖尿病史、家族史(青光眼/AMD/RP)、视力、眼压
2. **query_imaging_detail(retinal)** → 眼底影像是眼科诊断的基础（优先级最高）
3. 根据影像和临床特征初步分型:
   - 玻璃膜疣/黄斑萎缩 → 怀疑AMD → query_genetic_risk(by_gene, [CFH, ARMS2])
   - 微动脉瘤/出血/渗出 + 糖尿病史 → DR → 通常不需基因检测
   - C/D比增大/RNFL变薄 → 青光眼 → 家族史+时query_genetic_risk(by_gene, [MYOC, OPTN])
   - 色素沉着/光感受器丧失 → RP/IRD → query_genetic_risk(by_gene, [RHO, RPGR, USH2A, RPE65])（强烈推荐）
4. AMD补充: query_proteomics([VEGF, CFH, C3]) — 补体通路蛋白辅助分型
5. 整合证据 → submit_diagnosis

## 三、关键坑点
- DR诊断**不应依赖基因检测**，HbA1c+眼底影像已足够；基因增量价值极小
- AMD的CFH变异是风险因子而非确诊依据，需结合影像
- RP的**基因检测几乎总有价值**（指导基因治疗如voretigene neparvovec针对RPE65）
- 青光眼MYOC变异仅解释3-4%病例，阴性结果**不排除**青光眼
- UKB retinal影像数据可用，是眼科诊断最有价值的数据源
- 多数眼科疾病诊断以**影像为核心**，基因/蛋白为辅
- 吸烟史对AMD风险评估至关重要，务必检查
