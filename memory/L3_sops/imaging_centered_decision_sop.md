# 影像中心决策 SOP (Imaging-Centered Decision)

## 1. 影像在诊断决策中的核心地位

### 1.1 影像优先原则
- **形态学证据是诊断金标准的基础**
- 影像可直接诊断时，跳过分子检测
- 影像特征指导基因/蛋白选择，而非盲目查询

### 1.2 影像充分性判定标准

| 评估维度 | 充分标准 | 不充分标准 |
|---------|---------|-----------|
| **病灶显示** | 边界清晰，解剖定位明确 | 模糊、伪影、部分容积效应 |
| **特征典型性** | 符合疾病典型影像学表现 | 非典型、异质性表现 |
| **临床一致性** | 影像与症状/体征高度吻合 | 影像-临床不符或矛盾 |
| **技术质量** | 扫描参数适当，对比度良好 | 运动伪影、对比剂不足 |

## 2. 多模态影像决策节点

### Node 1: 结构影像评估 (CT/MRI)

**决策点**: 结构改变是否明确?

- **YES** → 进入Node 2 (功能评估)
  - 结构性病变已可见，评估是否需要功能/分子信息分期

- **NO** → 策略调整
  - 技术问题 → 影像复查
  - 早期病变 → 考虑功能影像 (PET/fMRI)
  - 疑似遗传病 → 即使结构阴性，仍需基因排查

### Node 2: 功能影像评估 (PET/fMRI/灌注)

**决策点**: 功能异常是否支持结构发现?

- **一致** → 证据强化，考虑是否需要分子分型
- **不一致** → 启动冲突解决
  - 结构(-)功能(+) → 早期病变/代谢异常为主
  - 结构(+)功能(-) → 陈旧病变/低代谢肿瘤

### Node 3: 影像-分子关联

**已知基因型-表型关联疾病**:

| 疾病 | 关键影像特征 | 关联基因 | 策略 |
|------|-------------|---------|------|
| 肥厚型心肌病(HCM) | 非对称性室间隔肥厚 | MYH7, MYBPC3 | 影像典型→必查基因 |
| 扩张型心肌病(DCM) | 左室扩张+收缩功能↓ | TTN, LMNA | 影像+基因联合 |
| ADPKD | 双侧多发囊肿 | PKD1, PKD2 | 影像诊断，基因确认 |
| 多发内分泌肿瘤 | 多腺体占位 | MEN1, RET | 影像发现→基因筛查 |

## 3. 影像可直接诊断的场景 (跳过基因/蛋白)

### 3.1 明确诊断标准
当同时满足以下条件，影像诊断即为终诊:

```
[影像充分性]
AND [典型影像学特征]
AND [临床表现符合]
AND [无遗传咨询需求]
```

### 3.2 典型场景示例

- **创伤性改变**: 骨折、出血、梗死急性期
- **获得性病变**: 动脉粥样硬化斑块、退行性变
- **影像典型且散发**:
  - 老年患者单发肺癌 (无家族史)
  - 典型部位的单发肝细胞癌 (无肝硬化背景)

## 4. 影像不充分时必须升级的场景

### 4.1 强制升级条件

| 条件 | 升级方向 | 理由 |
|------|---------|------|
| 影像模糊+家族史阳性 | 基因优先 | 遗传病表型变异大 |
| 多系统受累 | 基因Panel | 综合征可能 |
| 影像进展迅速+年轻 | 基因+蛋白 | 侵袭性疾病/遗传型 |
| 影像-临床严重不符 | 重新评估+基因 | 表型模拟/罕见变异 |

### 4.2 升级决策流程

```
影像不充分
    │
    ├── 技术因素? → 影像复查/换模态
    │
    ├── 早期病变? → 功能影像/PET
    │
    ├── 遗传怀疑?
    │   ├── 家族史/早发 → 基因Panel
    │   └── 已知基因关联 → 特定基因检测
    │
    └── 功能评估?
        ├── 需要分期 → 蛋白标志物
        └── 治疗监测 → 动态蛋白检测
```

## 5. 影像引导的精准分子检测

### 5.1 影像特征 → 基因选择

```
影像特征                    推荐基因检测
─────────────────────────────────────────
多发/双侧病变    →    遗传性癌症综合征基因
特定解剖分布     →    该部位特征性突变
早发+多灶       →    高外显率抑癌基因
影像+其他畸形   →    发育相关通路基因
```

### 5.2 影像特征 → 蛋白选择

```
影像特征                    推荐蛋白检测
─────────────────────────────────────────
肿瘤负荷大       →    肿瘤标志物 (CEA/CA125等)
炎症/感染       →    CRP, IL-6, PCT
心功能异常      →    NT-proBNP, Troponin
肝纤维化        →    FibroScan + 血清标志物
```

## 6. 执行流程图

```
接收病例
    │
    ▼
┌─────────────────┐
│ 1. 多模态影像评估 │
│    (结构+功能)   │
└─────────────────┘
    │
    ├── 影像充分且典型 ──► 直接诊断 (置信度>0.85)
    │
    ├── 影像不充分 ──────► 技术优化 / 升级模态
    │
    └── 影像不典型 ──────► 启动分子验证
             │
             ├── 遗传怀疑? ──► 影像引导基因查询
             │
             └── 功能评估? ──► 蛋白标志物检测
```

## 7. 质量指标

- **影像诊断率**: 无需分子检测即确诊的比例 (目标>40%)
- **影像引导率**: 分子检测选择由影像特征指导的比例 (目标>80%)
- **避免不必要基因查询**: 影像典型时跳过基因的比例
